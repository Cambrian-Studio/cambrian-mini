# Claims

Every claim this repository makes, where the code is, and the test that proves it.
`test/docs/claims.test.mjs` fails if a file named below does not exist, a named test is not in its file, or a row without a test is neither recorded nor next.

Status words:
- **tested**: tests in this repository prove it in both directions (the good case is accepted, the bad one refused). The test named in a row is the sharpest one.
- **tested, CI**: as above, and the Linux half only runs in CI (bubblewrap).
- **recorded**: shown by a real build or a real transaction kept in this repository, and re-checked by the judge check or the command the row names.
- **next**: not true yet. Those rows are together under [What is next](#what-is-next).
